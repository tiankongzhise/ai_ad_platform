# 教育行业广告×CRM数据平台 — MVP 开发任务列表

> **项目代号**：EduAdCRM-MVP  
> **生成日期**：2026-04-27  
> **来源文件**：market_research_report.md  
> **目标**：最短时间验证"广告投放 + CRM数据闭环"在教育行业的商业可行性

---

## 一、产品定位（来自研报）

### 原始需求引用
> "面向中小企业的'广告投放+CRM数据闭环+行业化落地方案'→ 低门槛 / 轻量接入 / 按需付费 / 自带行业模板"  
> "让客户30天内看到广告效果改善"  
> "无需开发，2小时内接入广告平台+CRM"

### MVP 范围决策
| 维度 | MVP 选择 | 排除（后续迭代）|
|------|----------|----------------|
| 渠道 | 抖音（巨量引擎）+ 百度营销 | 腾讯、快手、小红书 |
| 行业 | 教育培训（K12/职业教育/兴趣班）| 电商、医美、本地生活 |
| CRM接入 | Excel/CSV 文件上传 | API直连企微、销售易 |
| 核心价值 | 广告花费→线索→成交ROI可视化 | 自动投放优化、AI素材生成 |
| 交付形式 | Web SaaS（响应式）| 移动App |

**核心卖点（MVP验证话术）**：  
> "上传你的招生学员数据，连接抖音/百度广告账户，30分钟看清每条广告带来多少招生、花了多少钱。"

## 二、技术栈

```
后端：  Laravel 10 + PHP 8.2
前端：  Livewire 3 + FluxUI + Alpine.js + Tailwind CSS
数据库：MySQL 8
队列：  Laravel Queue（数据库驱动，无需Redis，MVP阶段）
文件处理：Maatwebsite/Laravel-Excel（Excel解析）
图表：  ApexCharts（前端可视化）
外部API：
  - 巨量引擎营销API（抖音）
  - 百度营销API
部署：  宝塔面板 + Nginx + MySQL（与现有环境一致）
```

### 模块 D：ROI 分析核心（MVP最高优先级）

#### [ ] D1：渠道成本×招生ROI 汇总仪表盘
**描述**：将广告花费数据与CRM成交数据按"渠道来源"关联，生成核心ROI卡片  
**核心指标（教育行业定制）**：
- 总招生人数 / 总广告花费
- 每招生成本（CPE = Cost Per Enrollment）
- 抖音 vs 百度 渠道ROI对比
- 近30天 / 近90天 趋势图

**验收标准**：
- 首屏4个核心指标卡片（总花费/总招生/CPE/ROI比值）
- 折线图展示近30天每日花费 vs 新增线索趋势
- 柱状图展示抖音 vs 百度 渠道对比
- 数据关联逻辑：CRM来源字段 = "抖音" / "百度" 时与对应渠道广告数据匹配

**要创建/编辑的文件**：
- `app/Http/Livewire/Dashboard/RoiDashboard.php`
- `app/Services/RoiCalculator.php`（计算逻辑）
- `resources/views/livewire/dashboard/roi-dashboard.blade.php`

#### [ ] D3：线索匹配引擎（广告→CRM关联）
**描述**：通过"渠道标识"将广告数据和CRM线索数据进行软关联  

**MVP关联逻辑（简化版，无需复杂归因）**：
```

  "抖音" / "巨量" / "douyin" / "tiktok" → 关联巨量引擎广告数据
```

### 数据关联设计说明（MVP简化版）
MVP 不做复杂的点击归因（需要落地页埋点，成本高），而是基于：
1. 用户在CRM中手动标注的渠道来源字段
2. 日期范围聚合

这样可以在不改造客户落地页的前提下，快速验证价值。后续版本再加点击追踪参数（UTM）归因。

### 图表库选型
使用 ApexCharts（而非ECharts），原因：
- 体积更小，适合Livewire响应式更新
- 与Alpine.js整合更顺畅
- 开源免费，文档完善

## 八、竞争差异化定位（教育行业话术）

给教育机构负责人/校长的一句话：  
> "把你们的招生台账上传进来，绑定抖音和百度账户，系统自动告诉你：每招一个学员，抖音花了多少钱，百度花了多少钱，哪个广告计划最值得加大预算。"

竞品无法提供的差异点：
- 神策/GrowingIO：太贵、太复杂，需要专业数据团队
- 通用CRM：没有广告费用ROI分析
- 广告平台自带后台：只有广告数据，没有成交/招生数据

我们的差异：教育行业专属模板 + Excel零门槛导入 + 30分钟看到结果
